# NextSkill

ระบบเรียนทักษะผ่านคอร์สและแผนที่บทเรียน ผู้เรียนลงทะเบียน เรียนตามลำดับ และสอบท้ายคอร์ส ผู้ดูแลจัดการคอร์ส เนื้อหาบทเรียน และคำถาม

## วิธีติดตั้งและรันบน Windows

ติดตั้ง .NET 10 SDK, SQL Server LocalDB และ `sqlcmd` จากนั้นเปิด PowerShell ในโฟลเดอร์ที่มีไฟล์ `NextSkill_205_247_261.slnx` แล้วรันคำสั่งตามลำดับ

```powershell
sqlcmd -S '(localdb)\MSSQLLocalDB' -E -C -b -i 'NextSkill_205_247_261/Database/Setup.sql'
sqlcmd -S '(localdb)\MSSQLLocalDB' -d NextSkillAuth -E -C -b -i 'scripts/LearningJourney.sql'
dotnet build NextSkill_205_247_261.slnx
dotnet run --project NextSkill_205_247_261 --launch-profile https
```

เปิด [https://localhost:7260](https://localhost:7260) หากเครื่องยังไม่เชื่อถือใบรับรองสำหรับพัฒนา สามารถตั้งค่าด้วย `dotnet dev-certs https --trust` แล้วเปิดแอปใหม่

`Setup.sql` สร้างฐานข้อมูล `NextSkillAuth` และตารางบัญชี ส่วน `LearningJourney.sql` เพิ่มตารางความคืบหน้า ใบประกาศ และรายการโปรด ทั้งสองสคริปต์เก็บข้อมูลเดิมไว้เมื่อรันซ้ำ

## ใช้งานแต่ละบทบาท

| บทบาท | ขั้นตอน |
| --- | --- |
| ผู้เยี่ยมชม | สำรวจหน้าแรก คลังคอร์ส และรายละเอียดคอร์สได้จาก `/` หรือ `/Home/Courses` |
| ผู้เรียน | สมัครที่ `/Account/Register` แล้วเข้าสู่ระบบ เลือกคอร์สและกดลงทะเบียนจากหน้ารายละเอียด ทำข้อสอบรายบทเพื่อเปิดบทถัดไป หลังผ่านทุกบทจึงเข้าข้อสอบท้ายคอร์สและรับใบประกาศเมื่อสอบผ่าน |
| ผู้ดูแล | รัน `NextSkill_205_247_261/Database/New-AdminInvitation.ps1` จาก PowerShell สำหรับผู้ดูแลฐานข้อมูล ใช้รหัสเชิญที่ `/Account/AdminRegister` แล้วเข้าสู่ `/Account/AdminDashboard` |

ผู้เรียนกดหัวใจจากคลังคอร์สหรือหน้ารายละเอียดคอร์สได้ เมนู **รายการโปรด** (`/Favorites`) เปิดเพลย์ลิสต์ส่วนตัวสำหรับดูคอร์ส แก้โน้ต ปักหมุด หรือนำคอร์สออก

ในหน้า Admin ให้สร้างคอร์สฉบับร่าง ใส่บทอ่านหรือวิดีโอในแต่ละบท เพิ่มคำถามรายบทและคำถามท้ายคอร์สผ่านคลังคำถาม แล้วเผยแพร่ คอร์สจากการนำเข้า JSON เริ่มเป็นฉบับร่างเช่นกัน

## ข้อมูลและการตั้งค่า

- บัญชี ความคืบหน้า คะแนน เลขอ้างอิงใบประกาศ และรายการโปรดจัดเก็บใน SQL Server
- คอร์สและคำถามจัดเก็บใน `NextSkill_205_247_261/Database/custom_courses.json` และ `custom_questions.json` แอปที่เปิดใช้ต้องมีสิทธิ์อ่านและเขียนโฟลเดอร์ข้อมูลของตัวเอง
- การนำขึ้นเซิร์ฟเวอร์ใช้ `ConnectionStrings__NextSkill` จากค่าลับของโฮสต์และกำหนด `AllowedHosts` ให้ตรงโดเมน สำหรับบัญชี SQL ที่ไม่มีสิทธิ์สร้างตาราง ให้รันสคีมาด้วยบัญชีผู้ดูแลก่อนแล้วตั้ง `Learning__AutoMigrate=false`
- ตั้ง `Privacy__ContactEmail` เป็นอีเมลที่ผู้ดูแลรับคำขอเกี่ยวกับข้อมูลส่วนบุคคล อีเมลนี้จะแสดงในหน้านโยบายความเป็นส่วนตัวและเงื่อนไขการใช้งาน
- สมัครบัญชีผู้เรียนได้จากหน้าเว็บ ส่วนบัญชีผู้ดูแลต้องใช้รหัสเชิญตามขั้นตอนด้านบน
