# NextSkill course covers

Generated with the built-in `image_gen` tool for the course catalog. Each cover was inspected and encoded as a 960px-wide JPEG (quality 88) for delivery. No generated text is used as course metadata. Editable prompts are recorded below; untouched PNG originals are retained under `artifacts/course-covers/originals` when available. Encoding script: `scripts/prepare-course-covers.ps1` (Windows PowerShell / System.Drawing).
