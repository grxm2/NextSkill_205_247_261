# ภาคผนวกตรวจข้อมูลและเนื้อหา NextSkill

ขอบเขตคือข้อมูลคอร์สและคำถามจาก repository ปัจจุบัน สูตรและการผูกข้อมูลในแอป และภาพปกที่ใช้จริงตาม mapping ในโค้ด ตารางนี้ใช้ `[อ่านโค้ด]` สำหรับข้อสรุปจาก source, JSON และไฟล์ภาพในเครื่อง การรันสคริปต์วิเคราะห์ไฟล์ยืนยันผลนับของไฟล์ แต่ไม่ยืนยันผลระบบที่รันอยู่หรือยอดในฐานข้อมูลเดิม ทุก path ขึ้นต้นจากโฟลเดอร์แอป `NextSkill_205_247_261/` เว้นแต่ระบุว่าเป็นไฟล์ที่ root ของ repository
