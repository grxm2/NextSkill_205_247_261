# ภาคผนวกการตรวจสิทธิ์ ความปลอดภัย และโครงสร้างข้อมูล

หลักฐานในเอกสารนี้เป็น **[อ่านโค้ด]** ทั้งหมด เว้นแต่แถวที่ระบุผลคำสั่งท้องถิ่นไว้ การพบช่องโหว่จากเส้นทางใน source มีระดับความมั่นใจแยกจากการยืนยันผลผ่าน HTTP ขอบเขตนี้ตรวจการควบคุมและข้อบกพร่องที่ควรแก้ โดยไม่มี payload ขั้นตอนใช้ช่องโหว่ หรือค่ารหัสเชิญที่ฝังไว้ ไม่มีการเปิดหรือเขียนฐานข้อมูลจริง พาธที่ขึ้นต้นด้วย `Controllers/`, `Services/`, `Views/`, `Models/`, `wwwroot/` และ `Database/` ด้านล่างอยู่ใต้โฟลเดอร์โปรเจกต์ `NextSkill_205_247_261/` เว้นแต่ระบุเป็นอย่างอื่น

## Admin endpoints และ Antiforgery

ทุกแถวใช้ `Authorize(Roles = "Admin")` ตาม source ดังนั้น Guest เข้าสู่ cookie challenge และบัญชีผู้เรียนเข้าสู่ access denied ที่ตั้งค่าไว้ การตรวจตารางนี้เป็น [อ่านโค้ด] ผล response HTTP ของแต่ละบทบาทต้องอ้างจากภาคผนวก runtime แยกต่างหาก

| Route | Method จาก source | Antiforgery | Storage | หลักฐาน |
| --- | --- | --- | --- | --- |
| `/Account/AdminDashboard` | ไม่จำกัด method ใน action, UI ใช้ GET | global filter ตรวจ unsafe method | SQL 2 ตารางบัญชี และ Learning 4 ตาราง, JSON คอร์ส/ข้อสอบ | `Controllers/AccountController.cs:230–238`, `Services/AccountStore.cs:168–205` |
| `/Account/AdminSaveCourse` | POST JSON | ยกเว้น global filter | `Database/custom_courses.json` | `Controllers/AccountController.cs:241–248`, `Services/AdminContentStore.cs:76–119,165–176` |
| `/Account/AdminDeleteCourse` | POST JSON | ยกเว้น global filter | `Database/custom_courses.json` | `Controllers/AccountController.cs:251–258`, `Services/AdminContentStore.cs:123–135,165–176` |
| `/Account/AdminUploadCourses` | POST form | ยกเว้น global filter | `Database/custom_courses.json` | `Controllers/AccountController.cs:261–282`, `Services/AdminContentStore.cs:139–176` |
| `/Account/AdminSaveQuestion` | POST JSON | ยกเว้น global filter | `Database/custom_questions.json` | `Controllers/AccountController.cs:285–292`, `Services/AdminContentStore.cs:226–250,295–306` |
| `/Account/AdminDeleteQuestion` | POST JSON | ยกเว้น global filter | `Database/custom_questions.json` | `Controllers/AccountController.cs:295–302`, `Services/AdminContentStore.cs:253–265,295–306` |
| `/Account/AdminGetQuestions` | GET JSON | มี attribute ยกเว้นที่ไม่จำเป็นสำหรับ GET | `Database/custom_questions.json` | `Controllers/AccountController.cs:305–310` |
