# Early NextSkill ocean illustrations

These illustrations originated with image generation using the visual reference from the early ocean-themed prototype. The project uses them as scene assets. Headings, navigation, cards, progress and controls are rendered in MVC views. The project copies were optimized to WebP.

Final assets are under `NextSkill_205_247_261/wwwroot/images/`:

- `sea-adventure-world.webp`: 1672 x 941. Hero with separate CSS cloud/mist parallax layers.
- `sea-coding-study.webp`: 768 x 512. Shared technology-course artwork.
- `sea-design-study.webp`: 768 x 512. Shared design-course artwork.

The two illustration families intentionally repeat across the four cards to reduce visual variety and clutter. They do not represent screenshots of actual course content.

## Compass emblem

`sea-compass-emblem.webp` is a 256 × 256 WebP with transparency.
