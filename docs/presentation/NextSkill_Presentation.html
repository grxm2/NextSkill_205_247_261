02 · ระบบฐานข้อมูลและการจัดเก็บข้อมูล

สถาปัตยกรรมฐานข้อมูลแบบ Hybrid (SQL Server + JSON Store)

แยกจัดเก็บข้อมูลธุรกรรมผู้เรียนไว้ในฐานข้อมูลเชิงสัมพันธ์ และจัดเก็บคลังบทเรียน/ข้อสอบในไฟล์ JSON เพื่อความยืดหยุ่นและปลอดภัย

SQL Server (NextSkillAuth) 14 ตาราง · Schema v4

จัดเก็บข้อมูลบัญชี ความคืบหน้า ผลสอบ ใบประกาศ และรายการโปรดที่ต้องรองรับการทำงานพร้อมกันและ Transaction

  • Parameterized Queries 100% ผ่าน Microsoft.Data.SqlClient ป้องกัน SQL Injection
  • Serializable + Profile Row Lock ใน LearningStore.WithProfileAsync (UPDLOCK, HOLDLOCK) ป้องกัน Race Condition ตอนส่งคำตอบหรือให้ XP
  • Schema Self-Healing & App Lock ใช้ sys.sp_getapplock ใน LearningSchema.cs เพื่อสร้าง/อัปเดตตารางอย่างปลอดภัยเมื่อเปิดแอปครั้งแรก
  • Composite PK & Foreign Key Cascade ป้องกันการลงทะเบียน/จบด่านซ้ำ และผูก CourseFavorites กับ Users
JSON Content Store (Database/) 23 คอร์ส · 241 ข้อสอบ

จัดเก็บข้อมูลหลักสูตร (custom_courses.json) และคลังข้อสอบ (custom_questions.json) พร้อมระบบล็อกไฟล์และนำเข้าได้ทันที

  • Cross-Process File Lock (.content.lock) ล็อกการเขียนไฟล์ทุกครั้งใน AdminContentStore.AcquireWriteLock() ป้องกันข้อมูลทับกัน
  • Atomic File Write เขียนลงไฟล์ชั่วคราว .content-{guid}.tmp แล้ว Flush(flushToDisk: true) ก่อน File.Move(..., overwrite: true)
  • Lifecycle & Soft Archive คอร์สใหม่เริ่มเป็น Draft (IsPublished=false), ลบคอร์สใช้ IsArchived=true และเช็ก HighestRecordedCourseIdAsync จาก SQL เพื่อไม่นำ ID เก่ามาใช้ซ้ำ
  • Strict JSON Import จำกัดขนาดไม่เกิน 1 MB, 1–100 คอร์ส/ไฟล์ และตั้ง UnmappedMemberHandling.Disallow
