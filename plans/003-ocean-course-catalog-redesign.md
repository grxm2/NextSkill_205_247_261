# แผนปรับหน้า /Home/Courses เป็นอ่าวแห่งการเรียนรู้

สถานะ: ผู้ใช้อนุมัติให้พัฒนาแล้ว โดยปรับรายการคอร์สจากภาพโมเดลเกาะเป็นภาพปกเฉพาะเนื้อหาแต่ละคอร์ส และคง Liquid glass ตามแนวทางที่เลือก

## ขอบเขต

ปรับหน้ารวมคอร์ส /Home/Courses ที่ผู้ใช้แนบมาเท่านั้น รักษาเส้นทางไปหน้ารายละเอียดคอร์สและระบบเรียนเดิม หน้า Home, Details, Learning/Island, Practice และระบบบัญชีอยู่นอกงานนี้ Navbar ใช้คอมโพเนนต์และหน้าตาเดิมโดยไม่เปลี่ยนไฟล์กลางเพื่อทำให้หน้าอื่นเปลี่ยนตาม

## สิ่งที่พบจากหน้าเดิมและ source

- หัวหน้าและช่องว่างด้านบนสูง ทำให้คอร์สชุดแรกลงไปต่ำกว่าพื้นที่ใช้งานหลักในภาพอ้างอิง
- Hero ยังใช้ course-container.svg ซึ่งไม่ต่อเนื่องกับท่าเรือไม้หลังคาฟ้าที่ปรับใน Home
- Courses.cshtml มีฟอร์มค้นหาแบบ GET, ตัวกรองหมวดหมู่, เรียงลำดับ, จำนวนผลลัพธ์, pagination และสถานะว่างอยู่แล้ว
- catalog.js โหลดความคืบหน้าจาก /Learning/State; การเลือกคอร์สและสิทธิ์เรียนยังเป็นหน้าที่ระบบ Learning
- course-pages.css ถูกใช้ร่วมกับหน้ารายละเอียด จึงต้องเพิ่ม style ที่จำกัดด้วย class ของหน้า catalog แทนการแก้ selector ร่วมกว้าง ๆ
- เอกลักษณ์เดิม: Prompt, ตัวหนังสือ navy, น้ำทะเลฟ้า/เทอร์ควอยซ์, ไม้สีน้ำผึ้ง, เกาะภาพประกอบและ Nimo

## แนวทางที่เลือก

ให้หน้าคอร์สเป็นอ่าวที่ผู้เรียนเข้ามาเลือกจุดหมาย มีท่าเรือเป็นจุดต้อนรับ ใช้ภาพปกที่สื่อเนื้อหาคอร์สบนการ์ด Liquid glass แทนโมเดลเกาะ จัดเป็นตารางที่อ่านเปรียบเทียบได้ ฉากทะเลเคลื่อนไหว ส่วนตัวหนังสือ ช่องค้นหา และปุ่มอยู่กับที่

### ส่วนบนของหน้า

- คง Navbar กระจกและสถานะเมนูคอร์สเรียน
- Hero กระชับ: ข้อความ "เลือกเกาะแห่งทักษะ ที่อยากออกเดินทางไป" พร้อมคำอธิบายสั้นหนึ่งถึงสองบรรทัด
- ฝั่งภาพเป็นท่าเรือไม้หลังคาฟ้าเดิม มี Nimo บนเรือในน้ำข้างท่า เงาสัมผัสและระลอกน้ำต้องอยู่ใต้จุดสัมผัสจริง
- กำหนดขนาด hero ร่วมกับพื้นที่ค้นหา ให้จอแล็ปท็อปเห็นช่องค้นหาและชื่อคอร์สแถวแรกได้ โดยไม่ต้องผ่านการเดินทางหรือรออนิเมชัน

### เครื่องมือเลือกคอร์ส

- รวม search, sort และปุ่มค้นหาในแถบกระจกที่เข้ากับ Navbar
- หมวดหมู่เป็นปุ่มทรงมนพร้อมข้อความเดิม มี selected/focus/pressed state ชัดเจน
- เมื่อเลื่อนพ้น Hero ให้แถบค้นหาและหมวดหมู่เกาะใต้ Navbar โดยชดเชยความสูงจริง และไม่ซ้อนแผงสองชั้นบนมือถือจอเตี้ย
- คงการค้นหาเมื่อกด Enter และชื่อ query parameters q, tag, sort, page, pageSize

### รายการคอร์ส

- เดสก์ท็อป 3 คอลัมน์ แท็บเล็ต 2 คอลัมน์ มือถือ 1 คอลัมน์
- ภาพปกเต็มกรอบแต่ละคอร์สมีเนื้อหาต่างกัน ใช้พาเลตและบรรยากาศริมทะเลร่วมกัน โดยไม่ใส่โมเดลเกาะในรายการคอร์ส
- ส่วนข้อมูลเป็นกระจกฝ้าสว่าง อ่านได้แม้คลื่นผ่านด้านหลัง: หมวดหมู่, จำนวนบทเรียนจริง, ชื่อ, คำอธิบายสั้น, ความคืบหน้าจริง และลิงก์ดูเส้นทาง
- คอร์สพร้อมเรียนกับคอร์สเร็ว ๆ นี้แยกด้วยข้อความสถานะ ไม่ใช้สีอย่างเดียว และไม่เปิดคอร์สที่ระบบยังไม่รองรับ
- คงลิงก์ชื่อและปุ่มไป /Home/Details/{id}; ไม่เปลี่ยนให้คลิกแล้วเริ่มเรียนทันที
- ไม่เพิ่มคะแนนรีวิว ราคา จำนวนผู้เรียน ระยะเวลา หรือความคืบหน้าที่ไม่มีข้อมูลจริง

## แผนอนิเมชัน

| ส่วน | พฤติกรรม |
| --- | --- |
| ทะเล | คลื่น 3 ระยะ เคลื่อนด้วยความเร็วต่างกัน เห็นการไหลของผิวน้ำต่อเนื่อง |
| การเลื่อน | ฉากไกลและฉากใกล้เลื่อนต่างระยะ เกาะและท่าเรือเกิดความลึก โดยใช้การเลื่อนหน้าแนวตั้งตามปกติ |
| ท่าเรือ | เปิดประตูครั้งหนึ่งเมื่อเลื่อนเข้าถึงตำแหน่งต้อนรับ ธง โคมไฟ และใบไม้ขยับตามลม |
| Nimo และเรือ | เรือโยกประมาณ 2-3px และหมุนไม่เกิน 1 องศาในน้ำข้างท่า เงาน้ำและตัวเรือเคลื่อนไหวสัมพันธ์กัน |
| นก | มีนกตัวเล็กบินผ่านมาเกาะเป็นช่วง ๆ เว้นพักระหว่างรอบ ไม่บินผ่านช่องค้นหาหรือข้อความคอร์ส |
| การ์ดเข้าจอ | ปรากฏครั้งเดียวต่อชุดด้วย opacity และ translateY ประมาณ 12px, 240ms, เหลื่อม 40ms; ถ้าสคริปต์ไม่ทำงานข้อมูลยังต้องแสดง |
| Hover | ภาพปกขยายเล็กน้อยภายในกรอบ และลูกศรตอบสนองใน 160-240ms บนเมาส์; ตัวหนังสือไม่ลอยตาม |
| ค้นหา/กรอง | ผลลัพธ์ตอบสนองทันทีตามการโหลดจริง ไม่มีฉากเรือเดินทางหรือคลื่นกวาดบังรายการ |

ใช้ motion tokens และ NextSkillMotion เดิม พักของตกแต่งเมื่อหลุดจอ แท็บไม่แสดง หรือผู้ใช้พักการเคลื่อนไหว รองรับ reduced motion ด้วยฉากนิ่งและการเปลี่ยนสถานะที่ยังเข้าใจได้

## ขั้นตอนพัฒนาเมื่อเลือกแนวทางนี้

1. จัดโครง Courses.cshtml ใหม่และสร้าง style เฉพาะ catalog โดยรักษาเนื้อหาและ data hooks เดิม
2. วางฉากทะเล ท่าเรือและภาพเกาะ ใช้ assets เวกเตอร์เดิมเป็นฐาน เก็บมิติ การซ้อนชั้นและ water contact ก่อนเพิ่ม motion
3. เชื่อม animation เฉพาะหน้าและระบบพัก motion เดิม ไม่โหลดตัวควบคุมการเดินทางของ Home ทั้งชุด
4. เพิ่ม glass material ที่เข้ากับ Navbar โดยวัด contrast บนฉากจริงทั้งกลางวัน/กลางคืนและมีพื้นทึบสำรอง
5. ตรวจการใช้งานและภาพรวมตามรายการด้านล่าง

## เกณฑ์ตรวจรับ

- การค้นหาชื่อ/ทักษะ/ผู้สอน, หมวดหมู่, การเรียงทุกแบบ, จำนวนผลลัพธ์และ pagination ยังตรงกับข้อมูลจริง
- ส่งต่อ q/tag/sort/pageSize ถูกต้อง เปลี่ยนตัวกรองแล้วไม่ค้างอยู่ในหน้าผลลัพธ์ที่ไม่มีอยู่
- ลิงก์ Details, Back และ query string เดิมยังใช้งานได้
- ความคืบหน้า/สถานะ guest/signed-in, loading, error/retry, empty state และการใช้งานไม่มี JavaScript ยังครบ
- ไม่มีเรืออยู่บนไม้ เกาะลอยพ้นน้ำ นกบังปุ่ม หรือ sticky controls ทับ Navbar
- ตรวจ 320, 390, 768, 1024 และ 1440px รวมจอเตี้ย 640/720px; ไม่มีการเลื่อนแนวนอนและเป้าหมายกดอย่างน้อย 44px
- ตรวจคีย์บอร์ด, focus, contrast ของกระจก, light/dark, reduced motion และปุ่มพักการเคลื่อนไหว
- Build และการตรวจ JavaScript ผ่าน พร้อมทดสอบภาพจริงบนหน้า Courses และ smoke test หน้า Home/Details ว่าไม่ได้เปลี่ยนตาม
